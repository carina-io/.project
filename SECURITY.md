# Security Policy

## Reporting Security Issues

The Carina maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/carina-io/carina/security/advisories/new) form.

For more details, see the [Carina security policy](https://github.com/carina-io/carina/blob/main/SECURITY.md).
